This folder contains supplementary materials related to the project, specifically analyses and reports that provide insights into GitHub projects and their categorization. Below is a description of each file contained within this folder:

## Files in the Appendix Folder

### 1. github_projects_domain_sub-domains_analysis.pdf
This file presents an analysis of GitHub projects categorized by their respective domains and sub-domains. It includes visualizations that help in understanding domain and sub-domain of the github projects.

### 2. output_categories.pdf
This file outlines the various categories of outputs generated by the github projects. It provides a framework for understanding how the results are organized and the criteria used for categorization.

### 3. unique_models_github_systems_analysis.pdf
This file contains an examination of unique models found in GitHub systems. It discusses the variety of models, their uses, and how they impact the overall field of machine learning and automated decision-making on GitHub.
